# HeisenBank: Quantum Fraud Detection & Hybrid Key Exchange

**HeisenBank** is a cutting-edge financial security framework designed to bridge the gap between classical banking infrastructure and the next generation of quantum-enhanced cybersecurity. By integrating Quantum Machine Learning (QML) and Post-Quantum Cryptography (PQC), HeisenBank addresses the evolving landscape of digital fraud and cryptographic threats.

## 🌌 Project Overview

### Quantum Fraud Detection (QML)
Utilizing a **Variational Quantum Classifier (VQC)**, HeisenBank analyzes transaction data to identify patterns invisible to classical algorithms.
* **Hilbert Space Advantage**: Maps transaction features into an exponentially large dimensional space for superior separation between legitimate and fraudulent activities.
* **Quantum Entanglement**: Captures complex inter-dependencies between transaction variables (e.g., location, time, and amount) using advanced quantum ansatz designs.

## 🛠️ Technology Stack

HeisenBank leverages the most advanced open-source libraries in the quantum and cryptographic ecosystems:

*   **Quantum Core**: [Qiskit](https://qiskit.org/) (Machine Learning & Aer)
*   **Post-Quantum Security**: [Open Quantum Safe (OQS)](https://openquantumsafe.org/)
*   **Data Intelligence**: Scikit-learn, Pandas, NumPy
*   **Development Environment**: Google Colab / Python 3.x
